# Python Programming Exercises

Python programming exercises completed as part of my Bachelor of Computer Science at UCLL.

The projects focus on **Python fundamentals, object-oriented programming, file handling and data management**.

## Projects

### Exercise 1 — Games & Players
- Object-oriented programming with classes
- Characters and players
- Getters and setters
- Data validation and exceptions
- Managing lists of objects

### Exercise 2 — Game Analysis
- Reading data from files
- Processing CSV-style data
- Dictionaries and lists
- Calculating averages
- Writing results to a file

### Exercise 3 — File I/O
- Reading and writing text files
- Functions as arguments
- Filtering lines based on conditions
- Working with `with open()`

### Exercise 4 — TikTok Agency
- Object-oriented programming
- CRUD operations
- File persistence
- Dictionaries and lists
- Error handling with `try/except`
- Interactive menu using `input()`

## Technologies & Concepts

- Python
- Object-Oriented Programming (OOP)
- Classes & Objects
- Getters & Setters
- Lists & Dictionaries
- Functions & Callbacks
- File I/O
- Exception Handling
- Loops & Conditional Statements
- String Processing
