# The Games Library

JavaScript examenproject gemaakt voor de opleiding Informatica aan UCLL.

Een webapplicatie waarmee games kunnen worden bekeken en beheerd. Het project is volledig gemaakt met **HTML, CSS en vanilla JavaScript**, zonder frameworks.

## Features

- Games bekijken en toevoegen
- Games zoeken, filteren en sorteren
- Games als favoriet markeren
- Games verwijderen
- Games ophalen via een externe API
- Minecraft server status controleren
- Werken met een lokale JSON-server backend

## Technologies

- HTML
- CSS
- JavaScript
- Fetch API
- REST API
- JSON Server

## JavaScript

In dit project heb ik onder andere gewerkt met:

- DOM manipulation
- Events
- Array methods zoals `map()`, `filter()`, `forEach()` en `sort()`
- Objects en destructuring
- Async/await en Promises
- Fetch API
- CRUD-operaties
- API's
- `setInterval()` voor polling
